# Machine Learning Lab 3

## Project Overview
This repository contains the work for Machine Learning Lab 3, focusing on classification and model evaluation.

## Project Files

- `lab-03 (1).ipynb` - Jupyter Notebook containing the lab implementation and analysis.
- `classification_escalation.csv` - Dataset used in the lab.

## Requirements

- Python 3
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Open the notebook using Jupyter Notebook.
4. Run the notebook cells in order.

## Dataset

The project uses the `classification_escalation.csv` dataset for classification tasks.
